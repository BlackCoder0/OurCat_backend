# 本地预发布验证记录

验证日期：2026-11-22。此记录针对配套 Windows x64 本地后端与 Android Demo，不代表生产环境或所有设备都经过测试。发布附件的具体源码提交和文件哈希见包内 `build-info.json`。

## 已通过

| 层次 | 环境与范围 | 结果 |
| --- | --- | --- |
| Backend 构建 | Windows、JDK 17.0.12、Maven 3.6.3；执行 `mvn -o package` | 9 个测试通过，JAR 构建成功 |
| demo 入口 | H2 文件库、启动保护、示例数据初始化 | 与生产配置隔离；重复初始化不复制示例记录 |
| 业务与权限 API | Spring Boot MockMvc + 真实 demo Profile | 注册/登录、头像、带图论坛/广场/猫咪上报、加入组织/管理员审核、任务分配/申领/日志/完成；无权限用户的相关操作被拒绝 |
| 本地图片 | 单元测试及正常登录后的 HTTP PUT/GET | 内容解码、类型/像素/体积校验、路径限制、错误票据、一次性使用、服务重建后读取 |
| Android 构建 | JDK 17、Gradle Wrapper、Android SDK 34 | Demo、Debug 构建通过；Release 合并清单仍禁止明文 HTTP |
| Android 实际界面 | Pixel 3、Android API 35 模拟器 | 后端地址修改并再次打开确认保存、正常图片验证码登录、头像选图/保存、带图论坛发帖、拍照后上报猫咪；选择 PNG 后生成真实 JPEG 上传，上报使用标注的示例坐标 |
| 同版本重启 | 包内 Java 运行时，启动器停止后重新启动原数据目录 | 原管理员登录、头像、帖子 ID/数量、配置与图片哈希保持一致；实际上报记录仍在 |
| 启动器端口检查 | 在同一端口已有本地服务时再次启动 | 清楚提示端口占用并退出，没有终止已有服务 |

API 测试使用测试代码中创建的验证码数据，应用没有固定验证码入口；界面测试填写正常图片验证码。角色流的端到端自动测试覆盖后端 API，不等于逐个点击了全部 Android 页面。

## 自己复核

Backend 仓库执行：

```powershell
mvn test
mvn package
```

Android 构建和地址解析检查见配套仓库的 `docs/validation.md`。Windows 包按[本地体验教程](local-experience.md)启动，停止后备份整个 `data` 目录。

## 尚未验证

- 实体手机安装、不同品牌 Android 和实际局域网/防火墙组合。
- 没有开发环境的另一台 Windows 电脑，以及 macOS/Linux 二进制发行包。
- 生产 MySQL/Flyway 回归、云端部署和现有线上数据。本次没有部署或重启云端。
- 所有 Android 角色页面逐项操作、跨版本数据库升级、大量并发和公网运营。
- 真实地图 Key、图片 AI、OSS、付费天气等外部服务；Demo 默认不启用这些能力。

当前应作为学习用预发布版。救助权限和上传编码也涉及共享业务代码，日后部署生产前仍需按自己的 MySQL、OSS 和客户端组合回归。
