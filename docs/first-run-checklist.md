## 交给体验者的步骤

1. 打开 Release，只下载 Windows ZIP，完整解压到可写文件夹。
2. 双击 start.cmd，等窗口出现 Started OurCatApplication。
3. 在手机安装包内 APK，让手机与电脑接入同一 Wi-Fi。
4. 在 App 登录页填写电脑实际局域网地址，确认出现验证码图片。
5. 注册普通账号并登录；检查示例猫咪、论坛和救助活动能否打开。
6. 发布一条测试帖子，选一张不含个人信息的测试图片，确认保存后能够看到。
7. 打开猫咪上报，确认页面明确说明使用示例位置；提交一次测试记录。
8. 在电脑 data/login-info.txt 中找到本机管理员账号，检查管理员入口可见。
9. 在启动窗口按 Ctrl+C 停止，再双击启动；确认之前的帖子、图片和账号仍在。
10. 停止后复制整个 data 文件夹作为备份。备份私人保存，不上传反馈或发给其他体验者。

这套步骤仅供本地试用，不需要公网端口转发、真实地图 Key 或付费 AI 服务。
