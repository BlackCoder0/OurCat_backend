状态：待执行。现有本地 H2 与模拟器结果不能作为生产 MySQL、OSS 和正式客户端的验收记录。本轮没有访问、重启或部署生产服务。

## 使用独立测试环境检查

1. 从备份恢复一套脱敏测试数据，确认连接的是独立 MySQL 和测试 Bucket。
2. 在测试库验证 Flyway 迁移、应用启动和主要实体查询。
3. 使用普通 Debug / Release 客户端登录，检查当前配置是否直接指向有效 HTTPS 接口；网络层不再自动跟随重定向。
4. 分别选择 JPEG、PNG 与较大图片，检查头像、论坛、广场和上报上传后的读取效果；相关临时文件会编码为 JPEG。
5. 按活动创建者、组织管理员、成员和无关用户分别操作任务分配、申领、日志与活动状态。
6. 验证广场“已解决”后活动、任务、猫咪状态和站内消息的关联结果。
7. 检查失败响应与日志，确认未泄露凭据；记录回滚方式后再决定正式升级。

外部服务测试使用测试账号及明确的费用上限。测试过程中不复用本地体验包自动生成的 JWT 或管理员配置。
